# دليل التشغيل التفصيلي — AdamN NMS

هذا الدليل يشرح **كل خطوة** من لحظة تنزيل المشروع حتى الاستخدام اليومي، وحل المشكلات، ونقل البيانات بين الأجهزة.

---

## 0) النسخة السريعة (ثلاثة أوامر)

إذا كان **Node.js 22.13 أو أحدث** مثبتًا على جهازك:

```bash
cd AdamN
npm install
npm start
```

ثم افتح المتصفح على: **<http://localhost:4000>**

ولمن يفضّل النقر بالماوس:
* **Windows:** افتح مجلد المشروع ثم دبل كليك على **`start.bat`**.
* **macOS / Linux:** من الطرفية داخل مجلد المشروع: `./start.sh`
* كلا الملفين يقومان تلقائيًا بـ: التحقق من Node → تثبيت الحزم إن لم تكن موجودة → تشغيل الخادم → فتح المتصفح.

## 1) المتطلبات

| المتطلب | التفاصيل |
|---|---|
| نظام التشغيل | Windows 10/11 (64-bit) · macOS 12+ · أي توزيعة Linux حديثة |
| Node.js | **22.13 أو أحدث** (لأن البرنامج يستخدم `node:sqlite` المدمج) |

### التحقق من إصدار Node

```bash
node -v
npm -v
```
* إذا ظهر رقم مثل `v22.22.3` ⇒ ممتاز.
* إذا ظهر أقل من `v22.13`، أو ظهرت رسالة «node غير معروف» ⇒ انتقل للخطوة 2.

## 2) تثبيت Node.js (مرة واحدة)

### Windows
1. افتح <https://nodejs.org> واختر **LTS** (نسخة 22.x أو أحدث).
2. نزّل ملف `.msi` وشغّله، واترك كل الخيارات الافتراضية (تأكد من تفعيل `Add to PATH`).
3. **أغلق أي نافذة Terminal/PowerShell مفتوحة** ثم افتح واحدة جديدة واكتب `node -v`.

### macOS
* الطريقة الأسهل: نزّل مثبّت `.pkg` من <https://nodejs.org>.
* أو عبر Homebrew: `brew install node@22`

### Linux (Ubuntu/Debian)
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
```

## 4) تثبيت حزم المشروع

افتح الطرفية **داخل مجلد المشروع** ثم:

```bash
npm install
```

* الأمر ينزّل حزمتين أساسيتين فقط + توابعهما (`express`, `exceljs`, `bcryptjs`, `cookie-parser`).
* يحتاج إنترنت مرة واحدة، ويأخذ عادة 10–30 ثانية.
* إذا كان جهازك خلف بروكسي: `npm config set proxy http://user:pass@proxy:8080` ثم أعد الأمر.

**للتحقق من سلامة البيئة بعد التثبيت:**
```bash
npm run doctor
```
سيطبع: إصدار Node، محرك SQLite، مسار ملف البيانات، حجمه، البصمة، المنطقة الزمنية، وعدد السجلات.

## 5) تشغيل البرنامج

```bash
npm start
```

سترى في الطرفية شيئًا مشابهًا:

```
[AdamN] daily job already ran for 2026-10-30
[AdamN] data file: C:\AdamN\storage\data\HDANA.db
[AdamN] driver: node:sqlite • schema v1
[AdamN] listening on http://localhost:4000
```

* **اترك هذه النافذة مفتوحة** أثناء استخدام البرنامج — إغلاقها = إيقاف البرنامج.
* أوقف البرنامج بـ `Ctrl + C` داخل الطرفية.
* بياناتك محفوظة على القرص في كل لحظة؛ إيقاف البرنامج لا يفقد شيئًا.

### تغيير المنفذ أو العنوان
```bash
# Windows PowerShell
$env:PORT=4001; npm start

# macOS / Linux
PORT=4001 npm start
```
أو أنشئ ملف `.env` بجوار `package.json` (يُقرأ تلقائيًا):
```ini
PORT=4001
HOST=127.0.0.1
ADAMN_OPEN=1
```

| المتغيّر | المعنى | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `4000` |
| `HOST` | `127.0.0.1` = هذا الجهاز فقط · `0.0.0.0` = الشبكة المحلية أيضًا | `127.0.0.1` |
| `ADAMN_HOME` | مجلد الإعدادات والنسخ الاحتياطية | `./storage` |
| `ADAMN_OPEN` | `1` = فتح المتصفح تلقائيًا | `0` (و`1` عند استخدام `start.bat`/`start.sh`) |

## 6) أول دخول

### الحالة (أ): تشغيل نظيف بدون بيانات
عند فتح <http://localhost:4000> ستظهر شاشة **«إعداد النظام لأول مرة»**:
1. اسم الحضانة.
2. اسمك الكامل (مدير النظام).
3. اسم مستخدم (حروف إنجليزية/أرقام، 3–32).
4. كلمة مرور (8 أحرف على الأقل وتحتوي حروفًا وأرقامًا) + تأكيدها.
5. زر **«إنشاء الحساب والبدء»** ⇒ تدخل للنظام مباشرة.

### الحالة (ب): استخدام البيانات التجريبية
```bash
npm run seed          # يضيف بيانات تجريبية (12 طالبًا، 5 موظفين، إيرادات، مصروفات، رواتب)
npm start
```
بيانات الدخول: **`admin` / `AdamN2026`** — غيّرها فورًا من: الإعدادات ← الأمان.
لإعادة توليد البيانات التجريبية من الصفر: `npm run seed -- --force` (يمسح الطلاب/الموظفين/السجلات فقط).

### نسيت كلمة المرور؟
لا تفقد أي بيانات:
```bash
npm run reset-password                          # يعرض أسماء المستخدمين
npm run reset-password -- --user admin --password NewPass2026
```
يحدّث كلمة المرور، يُلغي الجلسات المفتوحة، ويطلب تغييرها عند الدخول التالي.

## 7) إعداد أول مرة داخل البرنامج (مهم — 5 دقائق)

بعد الدخول، اذهب إلى تبويب **الإعدادات**:

1. **عامة**
   * اسم الحضانة والهاتف والعنوان (يظهر أعلى التقارير المطبوعة).
   * **المنطقة الزمنية** — اضبطها على `Africa/Cairo` أو منطقتك. كل الأعمار والأعياد والشهور تُحسب وفقها.
   * اللغة (عربي/إنجليزي)، العملة ورمزها، **قيمة الاشتراك الشهري الافتراضية**، **يوم الاستحقاق** (1–28).
   * تصنيفات الإيرادات والمصروفات (أضف/احذف ما يناسبك).
   * مفاتيح التنبيهات (أعياد الميلاد، غير المدفوعين، الرواتب) والنسخة الاحتياطية اليومية.
2. **ملف البيانات HDANA**
   * راجع المسار الحالي والحجم.
   * إن أردت ملفك في مكان محدد (مثل `D:\HDANA\HDANA.db` أو مجلد على Drive): اضغط **«إنشاء ملف بيانات جديد»** واكتب مسار المجلد واسم الملف ⇒ ينتقل البرنامج إليه ويبقى مرتبطًا به دائمًا.
   * إن كان لديك ملف HDANA جاهز: **«ربط ملف آخر»** أو **«بحث تلقائي عن ملفات HDANA»**.
3. **المستخدمون** (لمدير النظام): أضف حسابًا للمحاسبة أو مشرفة بدور «محاسب» أو «مشاهد» (قراءة فقط).
4. **الأمان**: غيّر كلمة المرور الافتراضية.

## 8) الاستخدام اليومي

### دورة العمل المعتادة
| متى | أين | ماذا |
|---|---|---|
| تسجيل طالب جديد | تبويب **الطلاب** | املأ البيانات (الاسم حروف فقط، الهاتف أرقام فقط، التواريخ `dd/mm/yy`) → ارفع الصورة → **حفظ** |
| أول الشهر | **الطلاب** | لكل طالب: اختر الشهر من القائمة المنسدلة، أدخل المبلغ (أكبر من صفر = «تم الدفع»)، أو اضغط الخلية في الجدول لتسجيل الدفعة بسرعة |
| نهاية الشهر | **الموظفون → الرواتب الشهرية** | اختر الشهر، عدّل الحوافز/المكافآت/الخصومات، ثم **حفظ مسير الرواتب** |
| أي مصروف | **المصروفات** | التاريخ + البيان + المبلغ + التصنيف |
| أي إيراد آخر | **إيرادات أخرى** | نفس الحقول |
| مراجعة الأداء | **المالية** | اختر السنة ⇒ جدول 12 شهرًا بالربح/الخسارة + تصدير Excel أو PDF |
| المتابعة اليومية | 🔔 أعلى الصفحة | تنبيهات: عيد ميلاد غدًا، غير المدفوعين، رواتب غير مسجلة |

### الطباعة وتصدير PDF
* زر **«تصدير PDF»** يفتح صفحة التقرير ثم نافذة الطباعة تلقائيًا.
* اختر الطابعة **«Save as PDF» / «حفظ كـ PDF»**، ومقاس **A4**، والاتجاه يُضبط تلقائيًا (أفقي للجداول).
* إن ظهرت خلفيات بيضاء: فعّل خيار **«Background graphics»** في نافذة الطباعة.

### تصدير Excel
زر **«تصدير Excel»** في كل تبويب ينزّل ملف `.xlsx` حقيقي (يفتح في Excel/Google Sheets/LibreOffice) مع صف إجماليات.

### إبقاء البرنامج يعمل دائمًا
* **Windows — تشغيل تلقائي عند بدء الجهاز:**
  1. اضغط `Win + R` واكتب `shell:startup` ثم Enter.
  2. أنشئ اختصارًا (Shortcut) لملف `start.bat` وضعه في المجلد الذي فُتح.
* **Windows — جدول مهام (بدون نافذة):**
  Task Scheduler → Create Task → Trigger: *At log on* → Action: *Start a program* →
  Program: `C:\Program Files\nodejs\node.exe`، Arguments: `--no-warnings server\index.js`، Start in: `C:\AdamN`.
* **macOS:** System Settings → General → Login Items → أضف `start.sh`.
* يمكنك تصغير نافذة الطرفية أو إخفاؤها؛ المهم ألا تُغلق.

> لا تحتاج تشغيل البرنامج طوال الوقت: التواريخ والأعمار وحالة «لم يدفع» تُحسب عند الفتح. لكن **التنبيهات والنسخة الاحتياطية اليومية** تُولَّد عند تشغيل البرنامج (أو كل 15 دقيقة وهو يعمل).

## 9) ملف البيانات HDANA — النقل والنسخ

### أين ملفي؟
افتراضيًا: `storage/data/HDANA.db`. تراه وتتحكم به من: **الإعدادات ← ملف البيانات HDANA**.

### تشغيل نسختين/جهازين على نفس الملف؟
❌ لا. ملف SQLite يُكتب من خادم واحد في اللحظة الواحدة. للعمل من جهازين استخدم:
* الجهاز الأول كخادم والحاسبات الأخرى تفتحه عبر الشبكة (القسم 10)، أو
* ملفًا لكل جهاز + تصدير/استيراد.

### نقل البرنامج إلى جهاز آخر
1. انسخ مجلد المشروع كاملًا (يمكن استثناء `node_modules` لتوفير المساحة).
2. انسخ **ملف HDANA** (أو احتفظ بمكانه على قرص خارجي).
3. على الجهاز الجديد: `npm install` ثم `npm start`.
4. من **الإعدادات ← ملف البيانات** اضغط **«ربط ملف آخر»** واختر مسار ملف HDANA.
5. إن نسيت الخطوة 4: البرنامج سيبحث تلقائيًا عن ملف يحمل نفس البصمة ويعيد الربط من نفسه.

### نقل الملف من مجلد لآخر (نفس الجهاز)
* انقله بالمستكشف عاديًا ثم شغّل البرنامج — يكتشف الغياب ويعيد الربط تلقائيًا.
* أو من داخل البرنامج: **«ربط ملف آخر»** وحدّد المسار الجديد.

### النسخ الاحتياطي
* **تلقائي:** نسخة يومية عند أول تشغيل في كل يوم (يمكن إيقافها من الإعدادات).
* **يدوي:** الإعدادات ← ملف البيانات ← **«نسخة احتياطية الآن»**.
* المكان: `storage/backups/` مع الاحتفاظ بآخر 14 نسخة (قابل للتغيير).
* **الاستعادة:** الإعدادات ← ملف البيانات ← النسخ الاحتياطية ← أيقونة ♻️ (يأخذ البرنامج نسخة أمان من الوضع الحالي أولًا).
* نسخة احتياطية تشمل **كل شيء**: الطلاب، الصور، المرفقات، الرواتب، السجلات المالية.

### نقل البرنامج من مجلد العمل إلى مجلد دائم
بعد أن تتأكد أن كل شيء يعمل، أغلق الطرفية، انقل مجلد المشروع كاملًا (مع `storage/`) إلى مكانك الدائم، وشغّله من هناك بنفس الطريقة.

## 10) الوصول من الموبايل/تابلت على نفس الشبكة (اختياري)

1. شغّل البرنامج هكذا (ويندوز PowerShell):
   ```powershell
   $env:HOST="0.0.0.0"; npm start
   ```
2. اعرف عنوان الجهاز: `ipconfig` (ويندوز) أو `ifconfig`/`ip addr` (ماك/لينكس) — مثلًا `192.168.1.20`.
3. اسمح للمنفذ 4000 في جدار الحماية (ويندوز: Windows Defender Firewall → Advanced Settings → Inbound Rules → New Rule → Port 4000 → Allow).
4. من الموبايل افتح: `http://192.168.1.20:4000` ثم سجّل الدخول باسم المستخدم الخاص بك.

> ملاحظة أمنية: في وضع `0.0.0.0` أي جهاز على نفس الشبكة يستطيع الوصول لصفحة الدخول؛ استخدم كلمات مرور قوية، وأغلق المنفذ في الراوتر عن الإنترنت.

## 12) أعطال شائعة وحلولها

| المشكلة | السبب | الحل |
|---|---|---|
| الطرفية تُغلق فورًا عند تشغيل `start.bat` | Node غير مثبت أو غير مضاف لـ PATH | أعد تثبيت Node مع خيار Add to PATH ثم افتح طرفية جديدة |
| `port 4000 is already in use` | نسخة أخرى تعمل، أو برنامج آخر يستخدم المنفذ | أغلق النسخة الأخرى أو `PORT=4001 npm start` |
| `No SQLite driver available` | إصدار Node قديم | حدّث Node إلى 22.13+ وتحقق بـ `node -v` |
| `npm install` يتوقف بأخطاء شبكة | إنترنت/بروكسي/فيروس | أعد المحاولة، أو `npm cache clean --force` ثم `npm install` |
| الصفحة بيضاء أو تظهر نسخة قديمة | كاش المتصفح | `Ctrl + F5` (أو نافذة تصفح خاص) |
| «ملف البيانات غير متصل» | تجري استعادة نسخة/إعادة ربط | انتظر ثانية وأعد التحميل؛ إن استمر راجع `npm run doctor` |
| الطالب لا يظهر بعد الحفظ | الفلتر (سنة/شهر/حالة/أرشيف) | اضغط «الطلاب» ← اضبط الحالة على «الكل» وامسح البحث |
| التنبيهات لا تظهر | لم يمرّ يوم/الشهر أو التنبيهات مغلقة | الإعدادات ← عامة ← تفعيل التنبيهات، أو الإعدادات ← النظام ← «تشغيل المهام اليومية الآن» |
| الطباعة تخرج بدون ألوان | إعداد المتصفح | فعّل Background graphics في نافذة الطباعة |
| نسيت كلمة المرور | — | `npm run reset-password -- --user admin --password NewPass2026` |
| أريد البدء من الصفر | — | `npm run reset -- --yes` ثم `npm start` (سيعرض معالج الإعداد) |

### أين تُخزَّن الأشياء؟
| المسار | المحتوى |
|---|---|
| `storage/data/HDANA.db` | **كل بياناتك** (طلاب، صور، مرفقات، رواتب، مالية) |
| `storage/app-config.json` | مسار ملف البيانات الحالي + بصمة آخر ملف (سبب «الربط الدائم») |
| `storage/backups/*.db` | النسخ الاحتياطية |
| `storage/logs/` | مجلد جاهز للسجلات |

> احتفظ بنسخة من `storage/data/HDANA.db` على قرص خارجي كل فترة — هذه أهم خطوة أمان.
